# 游戏人物 3D 卡通画像

## 范围与资料

本轮范围是孔子及《史记·仲尼弟子列传》77 位记名弟子，共 78 人。名单直接对应 `src/lib/biographies.ts` 汇集的人物档案，不将后世孔庙名录中的其他人物加入，也不把同字或异名的人物擅自合并。

`src/data/game-character-manifest.json` 为顶层数组，每项包含：

| 字段 | 含义 |
| --- | --- |
| `slug` | 与人物年表一致的唯一标识 |
| `name` | 站内人物档案采用的中文姓名；别称由档案提供 |
| `originalAsset` | 已在 `public/portraits/` 保存的后世画像路径 |
| `originalSource` | 对应画像的独立 Wikimedia Commons 文件来源页 |
| `cartoonAsset` | 实际发布文件 `/game/characters-3d/<slug>.webp`，全部78幅已完成 |

已核对清单有 78 个不同的 slug，全部与档案姓名匹配，78 幅原始参考图均在本地。画像的馆藏核对、题名异名、许可和逐幅来源继续以 `src/data/biography-portrait-research.json` 为完整依据。

春秋时期没有摄影照片。本轮参考材料是元代《至圣先贤半身像》的后世人物画像；图像题名能够帮助确认画家意图描绘的人物，不能证明古人的真实容貌。来源研究已为每幅图记录公有领域（PD-Art）许可。

## 统一画风与对外标注

设计目标是具有立体光照、圆润造型和柔和材质的 3D 卡通人物肖像。每幅依据对应的原画像保留冠帽轮廓、胡须形态、面部比例、服装主色及姿态差异，避免给 78 人套用同一张脸。使用统一的柔和自然光、鼠尾草灰背景、胸像构图和适合小屏识别的轮廓；无文字、水印或伪造的古代题签。

产品可使用简短图注：**“依据后世画像再创作的 3D 卡通形象”**。人物详情中的完整说明建议为：**“参考《至圣先贤半身像》中的后世画像创作，并非人物真实容貌。当前为具有立体风格的二维画像，不是可旋转的 3D 模型。”**

原画与卡通图应保持一一对应；人物详情提供“原画参考”与独立来源链接。原有历史画像用于来源查看，卡通图用于游戏角色表现。不得通过 CSS 光影或倾斜动画把未生成的原画标成已完成的 3D 卡通图。

下表以 `src/data/confucius-game.ts` 的 `characters` 为准。相同人物不因年龄或别称而重复计数。故事中未具名的家人、同伴、学生、负责者等仅是叙事情境身份，不能分配给名录中的某位弟子来补足画面。

| --- | --- | --- |
| 1 · 少年志学 `the-first-question` | 少年孔丘 → `confucius` | 家人、乡人，均为情境改编；叙事中的同伴也未具名 |
| 2 · 入庙问礼 `ask-about-everything` | 孔丘 → `confucius` | 郯子为历史人物，但不属孔门 77 弟子、当前目录无对应图；司礼者为情境改编 |
| 3 · 开门授业 `an-open-school` | 孔子 → `confucius` | 求学者为情境改编；学生、同伴为未具名群体 |
| 4 · 礼行于政 `a-place-in-government` | 孔子 → `confucius`；子路 → `zhong-you` | 鲁定公为历史人物，但不在 78 人范围、当前目录无对应图；齐国使者为情境改编；乡人、负责者、官吏为未具名情境角色 |
| 5 · 车辙向远 `roads-between-states` | 孔子 → `confucius`；子路 → `zhong-you`；子贡 → `duanmu-ci` | 隐者为章节集合称谓，史料背景涉及长沮、桀溺；两人均不在 78 人目录，不能把目录中的弟子画像当作隐者画像 |
| 6 · 陈蔡弦歌 `music-in-hardship` | 孔子 → `confucius`；子路 → `zhong-you`；颜回 → `yan-hui`；子贡 → `duanmu-ci` | 病者、求援者等为未具名门人，无新增的可确定人物身份 |
| 7 · 归鲁问学 `return-to-the-school` | 孔子 → `confucius`；子路 → `zhong-you`；冉有 → `ran-qiu`；公西华 → `gongxi-chi`；曾皙 → `zeng-dian` | 无新增具名角色；本章两景是未载确年的论语问答按晚年教学主题编排 |
| 8 · 斯文未已 `what-we-pass-on` | 孔子 → `confucius`；子贡 → `duanmu-ci`；曾参 → `zeng-shen`；颜回（追忆）→ `yan-hui` | 门人为未具名群体；颜回为追忆，不呈现为晚年仍在场 |

## 展现全部 78 位的建议

1. 在游戏首页与暂停界面提供“孔门人物馆”，所有 78 位都可浏览，显示“孔子与 77 位弟子”，以搜索支持姓名、字与别称。使用已有档案分组，提供“全部／德行／言语／政事／文学／其他弟子”，孔子单独作为老师呈现。
2. 人物卡使用对应的卡通图、姓名、常用字与一句有依据的档案摘要。点击后打开人物详情，包含卡通图、原画参考、已知事迹、资料来源及年表入口。史料仅存名字的弟子如实说明，不为填满卡片生成性格、名言或生平。
3. 章节人物区只显示本章有史料或改编说明支持的身份。郯子、鲁定公及匿名角色可用带明确身份标签的独立叙事图标，后续另寻参考资料时再扩展目录，不能借用其他人物的脸。
4. 在学习旅程中记录用户主动打开过的档案，使用“已认识 8 / 78”这样的浏览进度；不把打开档案写成历史相遇，不强制闯关才能查看资料。每章结束可推荐与学习主题相关的其他弟子档案，并明确是延伸阅读。
5. 首屏只加载可见人物图，按需加载后续卡片，保留图片长宽以减少跳动。轻微呼吸、入场与切换动画帮助辨认当前角色；禁用自动连续翻转与大量同时运动，尊重系统减少动态效果偏好。

## 上线前资产核验

图片生成阶段应将 78 幅结果分别保存到清单约定路径，检查输出文件存在、文件内容不同且与参考人物一致，再把完成状态用于产品文案。完整生成前，界面不得宣称“78 幅全部转换完成”。所有人物卡需要正常图片或明确的加载失败状态；缺图不能通过使用别人的卡通图掩盖。

## 完成记录（2026-09-06）

78幅已全部使用内置图像生成工具逐人转换，每次参照该人的原画像；弟子同时参照孔子首幅输出统一材质和光照。每幅结果都经过目视检查，并保留各自冠帽、胡须、服色和面型差异。原始PNG在本地保留，发布采用640×640 WebP，78幅总计约1.52MiB。全部文件可解码，像素SHA-256互不相同。

逐幅来源、发布路径和文件SHA-256见 [game-character-artwork.json](research/game-character-artwork.json)。游戏首页与章节使用对应画像，人物馆覆盖全部78位，支持姓名/字/别称搜索、类别筛选、原画切换、键盘翻页和人物年表链接。

重建网站图片：

```sh
node scripts/build-game-characters.mjs --source=/absolute/path/to/original-png-directory
node scripts/game-assets-qa.mjs
```

生成器原始PNG按人物slug命名；该脚本只做尺寸与文件格式优化。`--partial`仅用于开发中逐批接入，正式验收必须通过78幅完整性检查。
