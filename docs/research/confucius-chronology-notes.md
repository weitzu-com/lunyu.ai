# 孔子年表研究记录

检索日期：2026-09-05（工作区当地日期）。数据文件：`src/data/confucius-biography.ts`。

## 编排原则

“按年份”首先要求年份有依据，不能先造一张连续年度表，再用故事填满。本稿把有明确公年记载的活动作为骨架，其余使用约略区间、争议标签或未定年条目。`recorded` 表示所引文本有纪年，**不表示该叙述的所有细节已得到独立证实**。

负数表示公元前年；`null` 表示无法合理系年。不设公元0年。若年表出现区间，是材料所允许的宽泛定位，不表示孔子在该区间每一年都做同一件事。

《史记》是重要传记材料，但距孔子有数百年；《论语》是言行汇编，不是按时间写成的日记；《左传》有明确纪年，可用于对读，但其孔子叙事同样具有文本形成和解释的问题。现代学术、文博和机构资料用于校核与发现分歧，不因来源是机构就取消考证。

## 实际检索与阅读范围

使用网络搜索查找原典、大学研究材料、文博/文化机构条目；没有宣称穷尽互联网上所有页面。以下为主要检索词与访问结果：

- `孔子世家 史記 五十一年 五十六年`、`史記 卷047 孔子 年`。
- `孔子 生卒年 公元前551 前552`、`庚子 孔子生 公羊 穀梁`。
- `左傳 定公 十年 孔丘 相`、`定公十二年 仲尼命`。
- `仲尼聞之 見於郯子`、`孔子在陳 哀公三年`。
- `孔文子之將攻大叔也`、`季孫欲以田賦`。
- `孔子聞衛亂`、`孔丘卒 哀公十六年`。
- `孔子 诛 少正卯 史实 朱熹 荀子`。
- `孔子嘗為委吏矣 乘田`、`回年二十九 發盡白 蚤死`。

中国哲学书电子化计划（CTP）部分直开请求返回403，但搜索引擎索引可读到相关中文原文。相应段落还与维基文库、古典文库、识典古籍，以及学术论文/大学讲义引用的公版原文交叉核对。CTP 近期页面包含自动生成的英文翻译；本稿**不用这些英文翻译校定中国纪年**。检索结果曾把鲁定公十四年译为前526年，显然不合纪年。

已读项目 `AGENTS.md`，在新增 TypeScript 数据前阅读本地 Next.js TypeScript 指南；本子任务只编辑数据与本研究记录。

## 主要公开来源

### 传世原典

1. [《史记·孔子世家》CTP中文原文](https://ctext.org/shiji/kong-zi-shi-jia/zh)；[维基文库卷047](https://zh.wikisource.org/zh/%E5%8F%B2%E8%A8%98/%E5%8D%B7047)。用于家世、赴齐、任官、离鲁、游历、归鲁与晚年传承叙事。
2. [《史记·仲尼弟子列传》](https://ctext.org/shiji/zhong-ni-di-zi-lie-zhuan/zh)；[识典古籍“回年二十九”段](https://www.shidianguji.com/mid-page/7267254792639037477)。用于确认颜回传记实际只记二十九岁发白、早死，不能把二十九直接当成卒年年龄。
3. [《春秋左传》](https://ctext.org/chun-qiu-zuo-zhuan/zh)，重点为昭公十七、二十、二十五年，定公十、十二年，哀公三、六、十一、十二、十四、十五、十六年。[古典文库哀公全文](https://www.chinese-classics.org/read/confucius/chun-qiu-zuo-zhuan/chun-qiu-zuo-zhuan-ai-gong)可对读；[定公十年](https://ctext.org/chun-qiu-zuo-zhuan/ding-gong-shi-nian/zh)、[定公十二年](https://ctext.org/chun-qiu-zuo-zhuan/ding-gong-shi-er-nian/zh)的中文内容也由搜索索引核查。
4. [《论语》](https://ctext.org/analects/zh)。还核对本站既有 `analects.generated.json` 中公版原文；不使用其中尚未审校的白话导读字段作史料。引用以篇名和章句起句定位。
5. [《孟子·万章下》](https://ctext.org/mengzi/wan-zhang-ii/zh)，“仕非为贫也”章，委吏、乘田事。可交叉核对[中央研究院史语所“孔子的生平及弟子”相关页](https://www11.ihp.sinica.edu.tw/storage/w2_file/3684hjRwutZ.pdf)和台湾大学讲义所引原文。
6. [《荀子·宥坐》](https://ctext.org/xunzi/you-zuo/zh)，仅说明诛少正卯的叙事确实存在，不直接判作已证实的事件。

### 学术与机构资料

1. [Stanford Encyclopedia of Philosophy, “Confucius”](https://plato.stanford.edu/entries/confucius/)，2024年5月2日修订，第2节讨论生平来源、文本编纂与叙事。使用其史料分层方法；其个别日期和书目归属不直接照搬。例如该页把《公羊》生年概括为前551，与所见中文襄公二十一年材料不能直接等同。
2. [吉本道雅《孔子世家疏证》，京都大学文学院研究纪要第60号](https://repository.kulib.kyoto-u.ac.jp/bitstream/2433/261862/1/lit60_1.pdf)。检索可读到第12页生年辨析及第88页“哀三（前492）六十岁”相关对读。用于发现《史记》插入纪年与相对顺序的问题，不把数字化抓取日期当作论文发表年。
3. [至圣孔子基金会生年与诞辰考辨](https://confuciusfoundation.org.cn/newsinfo/4279651.html?templateId=1133604)。搜索索引提供二传与《史记》的对照原句；直开失败，未声称完整阅读页面全部内容。
4. [故宫博物院“孔子”词条](https://www.dpm.org.cn/lemmas/243277.html)。索引核对姓名、字及通行生卒年，未据其简略词条消除生年异说。
5. [《中外法学》“孔子诛少正卯案”在宋代的旅行](https://journal.pkulaw.cn/NewIssue/Detail/160361)及[期刊PDF](https://journal.pkulaw.cn/PDFFiles/%E2%80%9C%E5%AD%94%E5%AD%90%E8%AF%9B%E5%B0%91%E6%AD%A3%E5%8D%AF%E6%A1%88%E2%80%9D%E5%9C%A8%E5%AE%8B%E4%BB%A3%E7%9A%84%E6%97%85%E8%A1%8C.pdf)。用以确认后世确有支持、质疑及政治性引用。本文研究重点是宋代接受史，不等同于裁决先秦事件真伪。
6. [台湾大学孙中兴2015年课程讲义](https://ocw.aca.ntu.edu.tw/uploads/course_item_file/file/6139/104S102_AA07L01.pdf)，第84页引《左传·哀公十一年》孔文子询问军事、鲁人召孔子、季孙问田赋原文；[相关讲义第32页](https://ocw.aca.ntu.edu.tw/uploads/course_item_file/file/6150/104S102_AA10L01.pdf)对读《论语》返鲁正乐章及古注。原典引用只作交叉核查，课程的现代评论不大段转写。

济宁市政府、台中孔庙等网络年表也出现在检索中，但其中父卒、婚姻、入学、弟子出生等精细纪年不能仅凭通行年谱确定，未整表抄入。本页不是近现代年谱内容的改写。

## 内容与引用复核

- 全部人物事实、事件描述都配置原典定位或相关研究定位；简介用人物级引用，事件各自用事件级引用。
- 现代资料只借鉴有限的事实核对或方法，不大段改写；主体由公版中文原典独立转述。
- 《论语》章号在不同版本中会偏移。本站公版数据例如“子见南子”为6.26、“陈成子弑简公”为14.22、“在陈绝粮”并在15.1；因此除稳定章号外，多采用篇名＋起句。
- 检索摘要不是学术定论。发现来源冲突时保留分歧，不做“多数网页都这样写，所以必真”的判断。
- 本稿只涉及孔子本人，不以同名、后世追封或纪念活动补充其生平事件。
