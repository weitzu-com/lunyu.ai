# 《与孔子同行》游戏史料与改编说明

本地 Demo 的内容数据位于 `src/data/confucius-game.ts`。八章、十六个情境、四十八个选项覆盖志学、问礼、讲学、仕鲁、周游、困陈、归鲁和晚年传承。所有叙事、现代解释和后果由本项目编写；`quote` 才是明确标明出处的古文引用。

## 第一性原理与教学约束

- 学习发生于“看见处境—作出选择—理解后果—回看原文—再实践”，不以记住正确选项替代理解。
- 三种积累“仁 / 智 / 勇”描述本次实践的侧重，不是给孔子或玩家的品格打分。所有选项获得三点积累；每条路有收获、代价与下一步，没有惩罚性道德排名。
- 选择不会改变孔子的生卒或制造一个假历史结局。即时后果属于教学模拟，不冒称史实。
- 人物的困难、悲伤和不同意见应当保留。受苦本身不证明德性，暂时休整、承认局限和调整方法也有讨论价值。
- “有教无类”落实为不同基础的学习支持。早期学生使用明确标示的匿名改编角色，避免把尚未出生的弟子安排到孔子三十岁身边。

## 史料层次

1. **传世言行记录**：《论语》保存师生言行，多数章没有年月。本项目按篇名及起句定位，避免不同版本分章差异。它不是孔子亲笔日记，也不是现代意义的现场录音。
2. **有纪年的传世记载**：《左传》昭公十七年郯子来鲁、定公十年夹谷会盟、哀公十六年孔丘卒等有编年线索；“有纪年”不等于每个叙事细节均获独立证实。
3. **后出的传记叙事**：《史记·孔子世家》成于西汉，距孔子时代数百年。陈蔡弦歌、弟子轮番论道等据此标为传记叙事，不能与《论语》的简短记载混成同一证据层次。
4. **教学改编**：具体日程、资源分配、选项、对话式提示、反馈与结果均为改编。现代文字不加“子曰”伪作古文。

## 年代处理

- 年龄约依通行生年公元前551年和传统虚岁计算；生年另有前552年说，故不提供伪精确的周岁。
- 十五志学约系前537年，来自晚年回顾；三十而立不能证明孔子当年创校或“杏坛”已有固定场所。
- 青年问礼用前525年向郯子学习作有纪年支点；入太庙每事问无确年，按主题并置。
- 夹谷会盟采用《左传》定公十年，即前500年。完整任官升迁时间表不予补齐。
- 离鲁采用约前497—前496年起的通行分歧。周游的具体相遇多无确年，章节用宽泛区间。
- 陈蔡之困约前489年是传统系年而非《论语》独立纪年；标题、年龄与说明均作近似处理。
- 前484年归鲁是本章年代支点；“闻斯行诸”和“侍坐言志”编排于此不宣称谈话就发生在此年。
- 颜回确切卒年有争议，末章只是晚年追忆，不指定死于前482年或前481年。孔子卒于前479年，《论语》的形成属于其后传承。

核对日期：2026-09-06。中国哲学书电子化计划本次访问返回 403，实际核对使用维基文库的公版古籍原文；不引用百科二手概述代替古籍。

- [《论语》全览](https://zh.wikisource.org/wiki/論語/全覽)：志学、每事问、学思、教育、为政、子路问行、侍坐、绝粮、颜回、传承等。数据中的每个选项另附所参照篇名、起句或用意。
- [《春秋左氏传·昭公》](https://zh.wikisource.org/wiki/春秋左氏傳/昭公)：昭公十七年“仲尼闻之，见于郯子而学之”。
- [《春秋左氏传·定公》](https://zh.wikisource.org/wiki/春秋左氏傳/定公)：定公十年夹谷会盟、孔丘相礼及归田。
- [《春秋左氏传·哀公》](https://zh.wikisource.org/wiki/春秋左氏傳/哀公)：哀公十一年相关政事与十六年孔丘卒。
- [《史记·孔子世家》](https://zh.wikisource.org/wiki/史記/卷047)：生平叙事、离鲁、周游、陈蔡之困、归鲁及晚年。与本仓库既有孔子年表的材料分层原则保持一致。

本游戏不使用诛少正卯等争议故事制造道德奖励；不把孔子问礼于老子的流行精确年份、颜回某一卒年、固定七十二贤人数等作为确定事实写入情境。
