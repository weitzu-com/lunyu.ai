# 人物地理覆盖审校记录

审校日期：2026-09-06。基础名录为当前人物档案中的孔子及《史记》77位弟子，共78人。

## 范围与方法

地理实体以“可以独立说明、可以追溯到原文的空间概念”为单位，而不以搜索到的字串为单位。逐条核对人物 origin、summary、biography、events，并向其引用的《论语》《史记·孔子世家》《仲尼弟子列传》《左传》有关段落回查。对全册《论语》的人物相关专名另作人工补漏，补齐莒父、舞雩、泰山、石门、仪邑、太庙、中牟、颛臾等。

每条人物—地点关系保存独立的关系类型、文字证据和篇章定位。activity 表示文本记载实际活动（其年代或叙事仍可能有争议）；origin 表示籍贯；planned 包括愿景、意向、拟议或被拒任命；mentioned 表示事件、第三人、言论或争议记载所涉地点。关系不是自动继承：老师经过某地、任所属于某国、后学来自某地，都不能自动成为该人物的到访证据。

本次核对覆盖当前78份档案及上述相关原典段落，不宣称穷尽整个先秦史料中的所有地名，也不宣称复原了所有人物一生的行程。没有可靠地点的档案明确保留未定位状态。现代城市、省份只是古今位置参照，地图上的区域示意点不是人物确切足迹。

## 结果

- 地理实体：79。
- 人物—地点证据卡：157；活动65、籍贯13、提及70、意向9。
- 逐人审校：78 / 78；22人有活动、籍贯或意向地点，2人仅有事件提及，54人未能可靠定位。
- 有关联人物：24人。“有地理关联”不等于“到访过所有关联地点”。曾皙的两处关联都是志向。
- 原人物传记文件没有被本任务修改。公良孺在弟子名录中无地理资料，但《孔子世家》明确记其随行至匡、蒲，故依据跨篇章证据补录。

## 重要辨析与有意不收录

- 人物“郑国”、秦祖/秦冉/秦商/秦非、曹恤、左人郢、冉孺等姓名和字中的地名字形不产生地理关联；画像的收藏机构所在地也不属于生平。
- 卫与魏、齐与杞、鲁武城与南武城、陬邑与返卫叙事中的陬乡、防山与臧氏防邑、蒙会盟地与东蒙、尼山与尼谿田分别建实体，不默默合并争议同名地。
- 陈瓘赴楚时子路在卫；商瞿的后学为楚人不证明商瞿赴楚；高柴援引鄫衍、发阳的会盟先例不等于到场。
- 宰予任临淄大夫及卷入齐乱的记载有阚止同字辨误，齐国、临淄关联标为 disputed + mentioned。
- 孔子闻鲁国两庙失火时人在陈；获麟在大野的区域背景不足以确认观看之地就是猎获现场，均没有伪作当地足迹。
- 曾皙浴沂、风雩是愿景；樊迟在舞雩之下与孔子问答是另一条实际从游记录，分别保留。
- 费宰辞召、汶上退处、欲往中牟、欲居九夷、拟封尼谿田、临河欲见赵简子等与已经到达分开。
- 九夷、蛮貊、诸夏、夷狄是古代文化地理称谓，未赋固定疆界，未用来指认今天民族或现代行政区。
- 未新增无专名指向的陋巷、邻里、都邑、宗庙、城外、川上、渡口、沟渠、宗庙会同、海、四海、天下等为虚构景点；已有明确专名的太庙、长府、五父之衢则保留。
- “周南”“召南”在有关章句中是诗篇或篇组名称，不从书名推导行旅；《微子》篇礼乐官员的去处不强配给在册弟子。
- 《季氏》首阳章所叙伯夷、叔齐不在当前人物名录，该章也没有明示孔子为说话者，因此本次没有硬造“孔子—首阳”关联。
