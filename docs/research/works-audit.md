# 孔子与77名弟子著作归属核查

核查日期：2026-09-06。页面数据：src/data/biography-works-research.json。

本轮覆盖专题的全部78人，写入25条作品、编纂传统或相关文献说明，使用27项来源。记录对象、传授者、编纂者与实际作者分开处理；未为任何人虚填可确认的个人亲笔传世著作。

## 核查范围与判断规则

1. 以现有专题的《史记·仲尼弟子列传》77人名录为唯一人物边界，逐一对照本名、字和既有异名。孔伋、名家公孙龙及其余再传弟子不混入。
2. 基础核查为《史记》本传、《汉书·艺文志》的六艺略及诸子略、《隋书·经籍志》的相关经部、子部目录。目录能证明某时代已经著录某书、使用某归名，不能直接证明先秦人物亲笔。
3. 对重点归名文献，再核《四库提要》、朱熹大学章句、论语正义所辑郑玄佚说和高校、学术机构发表的研究。现代学术意见互异时保留争议，不把一种说法当定论。
4. 以人物命名的《论语》篇、上博竹书问答、史传、后人辑本属于相关资料。页面 work 项每条有 attributionLabel 与 statusLabel；works 数量不是本人自著数量。
5. 没有找到可确认著作的人，结论统一限定为“本次所核资料未见可确认为本人撰写的独立传世著作”。这不是断言其从未写作，也不是宣称已穷尽全世界所有文献。
6. 年代分别说明原始材料、编纂、抄写或后世伪托时代，不以抄本年代冒充作品原作年，不给未确定年代捏造年份。

## 必须保留的归属区分

- 孔子：《论语》为门人汇辑；六经包含前代积累，传统整理、传授与原创区分；春秋、易传保留古代归属说，孝经保留作者争议。
- 曾参：汉志《曾子》十八篇、隋志二卷（目录一卷）、大戴礼记十篇与后世辑本不是同一个可以无条件等同的版本。大学章句的曾子说是宋代理解，且自身区分口述与门人记录。
- 卜商：今本《子夏易传》不能作卜商自著；毛诗序、丧服传、尔雅增益属于有层次的传统归属；传经不等于书中每一字的作者。
- 端木赐：《子贡诗传》据四库提要为明代伪托；《鲁邦大旱》是竹简所载问答。
- 宓不齐：汉志著录《宓子》十六篇。原书已佚；《景子》三篇的小注明确称说宓子语、似其弟子，不可改署宓不齐。
- 漆雕开：汉志《漆雕子》十三篇小注“漆雕启后”的解释不可省略；以学派归名处理。不将同姓的漆雕哆、漆雕徒父自动列为作者。
- 冉雍：上博《仲弓》是人物言行资料；参与论语撰定保留为传统说。网页所传《敬简集》六篇没有核得可确认的早期著录、原书或佚文，因此仅在结论中注明未确认，不纳入已证实条目。
- 言偃：《礼运》以孔子与言偃问答成篇；言偃作、子游后学作等归属并存，不以问答者当确定作者。
- 颜回、高柴：上博《颜渊问于孔子》《子羔》以人物或起句题篇，不能当本人署名。
- 颛孙师、有若：《论语》的篇名、尊称或言论篇幅都不足以确立个人作者身份。
- 原宪字子思，区别于孔子孙孔伋；本页排除《子思子》《中庸》等误归。
- 孔子弟子公孙龙字子石，区别于战国赵国辩者；本页排除《公孙龙子》误归。
