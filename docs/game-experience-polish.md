# 阅读与探索体验优化

## 玩家任务与设计

玩家需要知道当前读到哪里、理解选择带来的结果，并能从查看人物或手记的支线回到故事。沿用松绿、青绿山水和后世画像，不改写原有历史内容。版面以清晰的阅读书签为识别元素：本章两幕与章末感悟构成真实进度。手机优先显示正文，章背景与人物可展开；桌面保留独立背景栏。

配色沿用纸色 `#f7f8f2`、墨色 `#233d33`、松绿 `#254d42`、玉色 `#e5ecdf`、辅助文字 `#657268`；标题与叙事使用宋体，操作与说明使用系统黑体。放大选项与说明，保留足够触控面积，避免把每个界面都变成大幅装饰画。

## 行为改变

- 点击“继续我的旅程”恢复当前标签页的阅读位置，保留已选择但尚未读完的反馈，以及章末原文和手记。书签只含位置与答案前缀；进度不匹配、账号进度替换或主动重置时失效。旧存档与禁用会话存储时保持原有继续逻辑。
- 人物馆与手记提供“回到旅程”。本章阅读位置可回看已完成场景；选中后其余选项收起，并提供明确的回看按钮。
- 手机章背景默认折叠，场景切换将正文移入视口。第一幕标题从约616px提前至165px，第一组选项从约882px提前至468px（375×812浏览器实测）。
- 手记统一显示字数与实际本地／云端保存状态；重新启程确认把焦点交给“保留旅程”，取消后返回触发按钮。
- 人物搜索与分类保留在当前会话；分类展示真实人数，详情上下位遵循筛选结果。关闭按钮与翻页持续可见，人物故事在新标签打开并说明。
- 动画与减少动态偏好同时覆盖弹窗背景。

## 验证

`qa:game` 包括11项游戏回归、78画像检查、账号同步与注册状态检查，以及10项阅读书签回归。生产构建、lint、SEO、人物年表和地理页面回归通过。浏览器进一步核对刷新反馈、章末恢复、返回旅程、完整16幕、手记导出、键盘焦点和320–1440px布局。验证产物在本地 `output/playwright/polish-*`。

公开注册仍按提供商真实配置保护；本次改动不把“注册暂未开放”表述为已经开放。
