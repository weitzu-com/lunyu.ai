# 地理页面：立体图册与阅读交互

2026-09-06。本轮覆盖地理目录及全部 79 个详情页，沿用原有地点、人物关系、地望说明与图片许可。

## 设计原则

先让读者辨认地点，再展开人物与文献。3D 用于纸面图册的观察角度、标签层次与图像景深；纸层不表示海拔，现代河道不表示春秋疆界或人物行程。缺少坐标的地理概念始终保留文字说明，不生成定位点。

- 图册支持地点选择、标记点选、立体／平面、左右旋转、鼠标拖动、80%–180% 缩放与复位。手机减少背景标签，保留页面纵向滚动；所有条目均可从地点选择器进入。
- 图像用保留完整画面的立体纸框呈现，鼠标移动时产生有限景深。图注、作者与许可仍可阅读。
- 目录提供类型计数、即时搜索、清除与空状态；`q`、`type` 参数在输入停顿 200ms 后写入 URL，导航前同步，浏览器返回可恢复。History 写入失败不会阻塞筛选。
- 详情目录显示当前章节与阅读进度；手机固定横向目录，锚点跳转保留标题焦点并避开目录遮挡。

## 实现边界

`places/layout.tsx` 中的 `GeographyMotion` 只增强服务器渲染的内容。它集中管理系统减少动态效果、本站地理动效偏好、进入视口时的一次渐显，以及图片指针事件。偏好保存在 `lunyu-geography-motion`；系统减少动态效果优先。节点移除、页面退出和关闭动效时解除观察与事件，停止动画和待处理帧。

`GeographyMap` 在服务器投影河道并裁减地点字段；`GeographyAtlas` 使用 CSS 3D 与 SVG，不引入 WebGL、3D 引擎或持续渲染循环。选择器中的地理说明、全部卡片及详情正文保留 SSR；关闭 JavaScript 后仍可阅读内容和普通链接。

- 已实测搜索、类型筛选、空结果、重置、详情返回恢复；移动阅读目录不遮挡目标标题，末段阅读进度到达 100%。
